# Privacy Policy for CHIWT (Comments How I Want Them)

## Overview

Comments How I Want Them is a Chrome extension designed to ease
the pain of having to select the "All Comments" drop down on every
Facebook post that you read.  This privacy policy explains how our
extension handles data and protects your privacy.

## Data Collection and Usage
Comments How I Want Them:
- Does NOT collect any personal information
- Does NOT track user behavior or analytics
- Does NOT send any data to external servers
- Does NOT store any information about your files or conversations

Any user preferences (such as enabled features) are stored exclusively
in your browser’s chrome.storage.sync or chrome.local area. This data
is never synchronized to external servers managed by the developer.

## Local File Access
The extension:
- Does not require any access to local files.

## Host Permissions
The extension requires access to:
  - www.facebook.com
  - web.facebook.com
  - m.facebook.com
  - Any and all subdomains of m.facebook.com (*.m.facebook.com)

These permissions are used solely to:
  - Find the comment drop-down on Facebook posts in order to select
    the "All comments" option.

This extension operates using 'Least Privilege' principles. It only
interacts with those specific DOM elements necessary to toggle comment
visibility It does not read or record private user data, messages, or
login credentials.

## Code Execution
All code execution happens locally within your browser. The extension:
- Only loads code bundled within the extension package
- Does not download or execute remote code
- Does not modify any content other than by selecting All Comments.

## Changes to Privacy Policy
We may update this privacy policy from time to time. Any changes will
be reflected in the extension's Chrome Web Store listing and in this
document.

## Contact
If you have any questions or concerns about privacy, please submit an
issue on the [GitHub repository](https://github.com/dougluce/chiwt)..
